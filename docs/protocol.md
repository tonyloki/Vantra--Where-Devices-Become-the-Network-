# VANTRA — Protocol Specifications

## Phase Status

*   **Current Phase:** Phase 0
*   **Status:** Foundation and project setup.

## Not Implemented Yet
*   Protocol buffer compiler setup
*   Serialization / deserialization of packets
*   Message packaging and ACK handshake

## Protocol Schema Definition
The protocol schema is defined under `proto/vantra_message.proto` using Protocol Buffers version 3.
It handles versioning and extensibility for future message types (e.g. file, audio).
