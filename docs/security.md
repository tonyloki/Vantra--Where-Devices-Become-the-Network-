# VANTRA — Security Architecture

## Phase Status

*   **Current Phase:** Phase 0
*   **Status:** Foundation and project setup.

## Not Implemented Yet
*   Peer authentication
*   Android Keystore integration
*   Key generation (Ed25519, X25519)
*   Payload encryption (ChaCha20-Poly1305)

## Target Security Model
The system enforces identity authentication and end-to-end payload encryption between peers.
Identity verification occurs during session establishment using public key exchange.
